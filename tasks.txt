Actual architectural/integration problems
intent_schema.json is loaded but not actually enforced.
Chat sessions are recreated for every message.
Agent errors aren't connected to the main UI.
Task success is reported too simplistically.
No cooperative agent cancellation exists.
CDP isn't verified before execution.
TaskGraph is disconnected from the actual agent pipeline.
TaskBar isn't synchronized with actual agent state.
Browser UI contains several non-functional controls.
Agent results are parsed through fragile regex over string representations.
Chat streaming modifies QTextEdit content in a fragile way.
Human browser actions and autonomous agent actions have no explicit state/ownership coordination.

And there's one codebase hygiene issue:

The exported project_codebase_dump.txt contains a second copy of the project itself, so the export is duplicated.
